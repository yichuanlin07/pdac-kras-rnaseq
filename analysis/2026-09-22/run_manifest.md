# Sample records

[run_manifest.json](run_manifest.json) contains the original run accessions, cell lines, BioSamples, Galaxy input numbers and ENA checksums.
The local P5/P5_v2 names differ from the public aliases, so identify files by run accession; the two KRAS runs remain separate because their repeat type is unresolved.
Control P1 used replacement inputs 251/252, P5 used recovered mates 175/176, and the original M1 inputs 1/12 were later replaced by verified mates 393/392.
Current sample annotations are in the [October tables](../2026-10-01/counts/sample_annotation.txt).
