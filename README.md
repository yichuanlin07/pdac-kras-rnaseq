# PDAC KRAS RNA-seq

This project compares control and KRAS siRNA samples from eight cell lines using [PRJNA980201](https://www.ebi.ac.uk/ena/browser/view/PRJNA980201).
The [latest results](analysis/2026-10-01/README.md) contain counts for all 17 runs and four figures, with KRAS M1 corrected; differential expression has not been run.
The [complete package](packages/PDAC_M1_corrected_2026-10-01.zip) includes the R and Python source code, count tables, figures and verification records.
Earlier work is in [analysis/2026-09-22](analysis/2026-09-22/README.md), and cleanup records are in [galaxy_backup](galaxy_backup/README.md).
