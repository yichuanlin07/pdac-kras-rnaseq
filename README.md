# PDAC KRAS RNA-seq

This project compares control and KRAS siRNA samples from eight cell lines using [PRJNA980201](https://www.ebi.ac.uk/ena/browser/view/PRJNA980201).
The [Week 4 results](analysis/2026-10-04-week4/README.md) contain DESeq2 and edgeR analysis, P5 sensitivity, method and paper comparisons, figures and reproducibility checks. The main merged-P5 analysis is exploratory because the two libraries' repeat type remains unresolved.
The [Week 4 source package](packages/PDAC_KRAS_Week4_source_2026-10-04_v1.zip) includes source code, inputs, full results and the [English report](reports/PDAC_KRAS_Week4_2026-10-04_v1.pdf).
The [October 1 counts](analysis/2026-10-01/README.md) and [earlier package](packages/PDAC_M1_corrected_2026-10-01.zip) retain the corrected M1 inputs and previous work.
Earlier work is in [analysis/2026-09-22](analysis/2026-09-22/README.md), and cleanup records are in [galaxy_backup](galaxy_backup/README.md).
