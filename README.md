# PDAC KRAS RNA-seq

This project compares control and KRAS siRNA samples from eight cell lines using [PRJNA980201](https://www.ebi.ac.uk/ena/browser/view/PRJNA980201).
The [Week 4 results](analysis/2026-10-04-week4/README.md) contain DESeq2 and edgeR analysis, P5 sensitivity, method and paper comparisons, figures and reproducibility checks. The main merged-P5 analysis is exploratory because the two libraries' repeat type remains unresolved.
The [current Week 4 source package](packages/PDAC_KRAS_Week4_source_2026-10-07_v6.zip) includes code, inputs, full results and the [English report](reports/PDAC_KRAS_Week4_2026-10-06_v4.pdf). The scripts are formatted and contain no comments or docstrings. Version 6 also updates the source checksum lists. Analysis logic, results and reports are unchanged. The report explains P5 handling and uses wider paragraph gaps, padded table cells and light guides on the DE-count and paired-expression plots. Earlier [version 1](packages/PDAC_KRAS_Week4_source_2026-10-04_v1.zip), [version 2](packages/PDAC_KRAS_Week4_source_2026-10-06_v2.zip), [version 4](packages/PDAC_KRAS_Week4_source_2026-10-06_v4.zip) and [version 5](packages/PDAC_KRAS_Week4_source_2026-10-07_v5.zip) packages remain available.
The [October 1 counts](analysis/2026-10-01/README.md) and [earlier package](packages/PDAC_M1_corrected_2026-10-01.zip) retain the corrected M1 inputs and previous work.
